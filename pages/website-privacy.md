# Website Privacy Policy

This policy covers the **Aster ID website** — the landing pages you are browsing at [aster.place](https://aster.place).

It is separate from our [Privacy Policy](/privacy), which covers the Aster ID services you sign in to: the **Personal Data Server (PDS)** and the **Portal**. If you have an Aster account, your account data is described there, not on this page.

## Current Status

This website currently collects no user data, and has no privacy-policy scope beyond this page; when that changes (such as through forms that collect interest in signing up), this policy will be updated and published here in full. Anything you read on the [Privacy Policy](/privacy) applies to the PDS and Portal, not to the Aster ID website.
